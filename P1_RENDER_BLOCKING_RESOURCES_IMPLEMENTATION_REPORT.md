## 2. Audit Findings

### Initial Page Load Resource Inventory for Home (`/`)

1. **Main CSS Bundle (`index-[hash].css`)**:
   - **Size**: 60.92 kB raw (11.87 kB gzipped)
   - **Loading Mechanism**: Inlined directly into a `<style>` tag in `<head>` by `scripts/prerender.js` during static pre-rendering build.
   - **Render-Blocking Status**: Non-blocking network-wise (0 HTTP requests required for CSS on initial paint).
   - **Classification**: A — Critical (Required for styled initial render).
   - **Action**: Preserved inlined CSS strategy. Route-specific CSS is already code-split by Vite for lazy-loaded routes.

2. **Primary Body Font (`Playfair Display` woff2)**:
   - **Size**: 21.85 kB (`playfair-display-latin-400-normal-[hash].woff2`)
   - **Loading Mechanism**: Discovered via `@font-face` inside inlined CSS `<style>` tag.
   - **Render-Blocking Status**: Optimizable delivery.
   - **Classification**: B — Critical but optimizable.
   - **Action**: Updated `scripts/prerender.js` to dynamically inject `<link rel="preload" href="/assets/playfair-display-latin-400-normal-[hash].woff2" as="font" type="font/woff2" crossorigin>` in `<head>` of pre-rendered HTML files.

3. **Secondary Display Font (`Instrument Serif` woff2)**:
   - **Size**: ~15 kB (`/fonts/instrument-serif-v5-latin-regular.woff2`)
   - **Loading Mechanism**: Preloaded in `index.html` via `<link rel="preload">`.
   - **Classification**: A — Critical (used for headings and brand pills).
   - **Action**: Preserved.

4. **Third-Party Scripts (`adsbygoogle.js` and `gtag.js`)**:
   - **Loading Mechanism**: Previously placed at the bottom of `<body>` as `async` scripts.
   - **Render-Blocking Status**: Non-critical for initial viewport paint, but caused early CPU and network contention during initial font/hydration downloads on slower connections.
   - **Classification**: D — Third-party / Non-critical.
   - **Action**: Deferred third-party script loading until after initial window `load` event and idle callback (`requestIdleCallback`).

5. **JavaScript Modules**:
   - **Main Entry Chunk (`index-[hash].js`)**: 294 kB raw (91 kB gzipped), loaded via `<script type="module">` (natively deferred by ES module specification).
   - **Preloaded Chunks (`jsx-runtime-[hash].js`, `auth-[hash].js`)**: Loaded via `<link rel="modulepreload">`.
   - **Classification**: A — Critical (Required for React hydration and interactive state).
   - **Action**: Kept intact. Route components (PDF Viewer, Dashboard, Syllabus Flowchart) remain cleanly code-split in lazy chunks.

---

## 3. Root Cause

1. **Third-Party Network & CPU Contention during Critical Paint Window**:
   `adsbygoogle.js` and `gtag.js` were fetched immediately when the HTML parser reached the bottom of `<body>`. While marked `async`, initiating third-party network fetches during initial HTML parsing created network socket competition and main-thread execution overhead while the browser was fetching body fonts and primary JS chunks.

2. **Late Discovery of Primary Body Font (`Playfair Display`)**:
   While `Instrument Serif` was explicitly preloaded, `Playfair Display` (the primary body typography) was only discovered when the browser parsed the inlined CSS `@font-face` rule. Preloading the hashed `.woff2` asset generated by Vite ensures top-priority HTTP request initiation at HTML header parse start.

## 4. Changes Made

| File Path | Change Summary | Reason | Safety Justification |
| :--- | :--- | :--- | :--- |
| `index.html` | Preserved `gtag` dataLayer/function stub inline while moving `adsbygoogle.js` and `gtag.js` network script injection into a `window.addEventListener('load')` + `requestIdleCallback` handler. | Prevents third-party network/CPU contention during initial page paint. | Inline tracking calls are buffered in `window.dataLayer` and processed as soon as scripts load post-render. |
| `scripts/prerender.js` | Added detection for `playfair-display-latin-400-normal-*.woff2` in `dist/assets/` and injected `<link rel="preload" ...>` into `<head>` during pre-rendering. | Ensures high-priority font discovery for primary body text at HTML parse start. | Preloads only the exact `.woff2` asset built for production; falls back gracefully if absent. |
| `scripts/__tests__/prerender.test.ts` | Added unit test verifying `index.html` contains deferred third-party script loading logic for `adsbygoogle` and `gtag`. | Prevents regression in third-party script loading strategy. | Pure unit test assertion. |

## 6. Expected Impact

1. **Faster First Contentful Paint (FCP)**: Preloading `Playfair Display` alongside `Instrument Serif` eliminates font discovery latency.
2. **Reduced Network Contention**: Deferring AdSense and Google Analytics past window `load` frees up 100% of network sockets and main-thread bandwidth during initial paint and LCP frames.
3. **Zero TBT Penalty**: Main thread execution remains uninterrupted during initial render.

---

## 7. Remaining Opportunities

1. **JS Chunk Size Optimization**: Further refine `auth-[hash].js` or vendor chunk splitting if future PageSpeed reports indicate hydration CPU bottlenecks on low-end mobile devices.
2. **Service Worker Caching**: Consider offline/service worker caching for static font assets to achieve 0ms font fetch latency on repeat visits.
